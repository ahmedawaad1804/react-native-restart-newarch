# Changelog

Changes are grouped by published package version. Historical entries below summarize repository changes; they do not imply native runtime verification.

## Unreleased

- Clarify the package description and simplify README presentation.
- Add a build/runtime compatibility matrix, API reference, troubleshooting, and release links.
- Document that the historical React Native peer range is not a tested support guarantee.
- Remove redundant badges and the unavailable Bundlephobia badge.
- Add release notes and a maintainer release checklist.
- No restart implementation changes.
